  VERIFIED: class_names.txt content matches expected order ✅

Support modules loaded from source clone:
  preprocessing.py — EXISTS ✅
  motion.py        — EXISTS ✅
  smoothing.py     — EXISTS ✅

Adapter preprocessing chain (verified against source):
  1. landmarks_to_pixels(hand_landmarks, width, height) → (21, 2) float32 pixels
  2. OneEuroFilter smoothing on raw pixel landmarks
  3. MotionTracker.update(smoothed) — raw pixels divided by hand size
  4. normalize_landmarks(smoothed) → [0,1] canvas coords, aspect preserved
  5. render_skeleton(normalized, size=96) → (96, 96, 3) uint8 RGB skeleton
  6. model_input(skeleton) → (1, 96, 96, 3) float32 batch
  7. ONNX inference → (1, 26) logits
  8. softmax(logits) → 26 probabilities
  9. Moving average over last 8 probability vectors (SMOOTHING_WINDOW)
  10. MotionTracker.classify(label) — may override i→j or d→z based on motion

Preprocessing consistency:
  - Source clone and adapter use the SAME preprocessing.py (loaded via importlib
    from the clone path, not copied) ✅
  - render_skeleton output is RGB (not BGR) — matches training ✅
  - HAND_FILL = 0.7, CANVAS_SIZE = 192, MODEL_INPUT_SIZE = 96 — shared ✅
  - Canvas drawn above target and downsampled with INTER_AREA ✅

Motion rules (J/Z):
  - J_SHAPES = {"i", "j"}, Z_SHAPES = {"d", "z"} — only overrides compatible shapes
  - J: descent ≥ 0.20 + hook ≥ 0.12 + path ≥ 0.55 hand widths
  - Z: reversals ≥ 2 + horizontal ≥ 0.30 + path ≥ 0.55 hand widths
  - Rule-based, not learned (documented limitation)

Stability buffer (StableTextBuffer):
  - commit_frames default = 10, confidence_threshold default = 0.75
  - Commits letter only after consecutive agreeing inference updates above threshold
  - Keys: C clear, Backspace undo, Space separator, R repeat, Q quit

            structurally consistent with source code but not runtime-tested.
  Fix: Install ONNX Runtime in .venv-alphabet, then run a one-off inference
       probe to confirm tensor contract.
  Retraining needed: No

  Severity: Medium
  Evidence: Webcam access excluded per audit rules; .venv-alphabet does not exist.
  Impact: Cannot confirm end-to-end webcam → MediaPipe Hands → ONNX → letter
          output pipeline works on this hardware.
  Fix: After .venv-alphabet setup, run ./run_sign2text_alphabet.sh with camera.
  Retraining needed: No

Issue 4 — Source clone LICENSE note on ONNX weights
  Severity: Low (informational)
  Evidence: docs/ALPHABET_MODE.md and source LICENSE state ONNX weights are NOT
            covered by the MIT code license; weights derive from GPL-2.0 +
            CC0 datasets. Integration references the local clone only, does not
            copy or redistribute weights.
  Impact: Redistribution of the combined system may require checking dataset
          license terms.
  Fix: Review source LICENSE and dataset terms before any redistribution.
  Retraining needed: No
