Missing-landmark handling:
  - Missing pose: all 99 pose features zero-filled
  - Missing left hand: all 63 LH features zero-filled
  - Missing right hand: all 63 RH features zero-filled
  - Missing/invalid face index: that landmark's 3 values zero-filled
  - NaN/inf: np.nan_to_num(keypoints, nan=0.0, posinf=0.0, neginf=0.0)

Normalization (delegated to source app/main.py normalize_sequence()):
  - (sequence - mean) / std, where mean and std are loaded from mean.npy/std.npy
  - std is sanitized: std = np.where(std == 0, 1.0, std) — no division by zero
  - mean and std shapes (1,1,444) are squeezed to (444,) before use
  - Verified: std has no zeros, no non-finite values, all positive
  - Verified: mean/std shape matches feature size (444)

Sequence handling:
  - Rolling window of exactly 40 consecutive frames (deque maxlen=40)
  - No padding; inference only when buffer is full (40 frames)
  - Batch dimension added: (1, 40, 444) — matches model input contract
  - Data type: float32 throughout

Adapter tensor-contract validation (sign2text/recognizers/words/adapter.py):
  - Checks tuple(model.input_shape) == (None, 40, 444) — VERIFIED MATCH
  - Checks output_shape[-1] == num_classes (24) — VERIFIED MATCH

G. WORD-MODE GUI AND STABILITY AUDIT
================================================================================

GUI (tools/run_word_demo.py):

  Window: "ASL Isolated Word Recognition" (cv2.WINDOW_GUI_NORMAL | WINDOW_AUTOSIZE)
  Camera mirroring: cv2.flip(frame, 1) — matches source app behavior
  Landmark drawing: pose (yellow), left hand (green), right hand (red) — face
    points retained as inference features but NOT drawn (per documentation)
  Live prediction display: "Live: LABEL  XX%" with color coding (green if ≥
    confidence threshold, amber otherwise)
  Top-3 predictions shown with confidences
  Stability progress bar: "Stable: XX%"
  Recognized word display: "Recognized: WORD (none)" at bottom
  Controls: Q = quit, C = clear text

Prediction cadence:
  - PREDICTION_INTERVAL = 1 (predict every frame once buffer is full)
  - Inference runs on the main thread (no separate worker thread — different
    design from GRU mode, but acceptable since LSTM inference is fast)
  - Updates only when buffer is ready (40 frames)

Stability handling (StableWordText):
  - stable_updates = 3 (demo default), confidence_threshold = 0.60
  - A word commits only after N consecutive confident predictions at/above
    threshold
  - A held sign does NOT append repeatedly (label must change then return, or
    buffer must clear)
  - Low-confidence predictions (< 0.60) reset the streak — no false commits
  - Invalid labels (e.g., "world") are rejected — not in class_names
  - User can clear accumulated text with 'C'

Error handling:
  - Webcam not found: RuntimeError with clear message, resources released
  - Frame read failure: RuntimeError, resources released
  - Missing holistic_landmarker.task: FileNotFoundError, no download attempted
  - Missing word model artifacts: FileNotFoundError with specific paths
  - Insufficient frames (< 40): status "Collecting frames N/40", no inference
  - Non-finite sequence: status "invalid input", no crash
  - Bad model output shape: status "inference error", no crash
  - No hand detected: sequence cleared, text streak reset, status "No hand detected"

Resource cleanup (finally block):
  - capture.release() — camera released
  - task_landmarker.close() — MediaPipe detector closed
  - recognizer.close() — model reference dropped, source module removed from sys.modules
  - cv2.destroyAllWindows() — all OpenCV windows closed

No label mixing: word labels (24 isolated signs) and alphabet labels (26 letters)
are completely separate. The GRU model (271 gloss classes) is not used as a
fallback anywhere in the word pipeline.
